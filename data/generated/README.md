# Generated Answers

This directory contains GraphRAG-generated answers for evaluation questions from the local PubMedQA dataset.

## Directory Structure

```
generated/
├── local/     # Answers generated using GraphRAG local search
└── global/    # Answers generated using GraphRAG global search
```

## File Format

Each JSON file contains:

```json
{
  "metadata": {
    "total_questions": 10,
    "successful": 10,
    "failed": 0,
    "success_rate": 1.0,
    "average_response_time": 13.76,
    "generation_timestamp": "2025-10-21T14:36:35.693558",
    "search_method": "local"
  },
  "results": [
    {
      "question_id": 0,
      "question": "Are group 2 innate lymphoid cells...",
      "generated_answer": "## Increased ILC2s in Chronic...",
      "ground_truth_answer": "As ILC2s are elevated in patients...",
      "ground_truth_doc_ids": ["25429730"],
      "search_method": "local",
      "response_time": 16.12,
      "success": true,
      "metadata": {
        "source": "local_passages",
        "final_decision": "yes",
        "dataset_split": "train",
        ...
      },
      "timestamp": "2025-10-21T14:30:33.408247"
    }
  ]
}
```

## Key Fields

- **`question`**: Original question from PubMedQA dataset
- **`generated_answer`**: Answer generated by GraphRAG
- **`ground_truth_answer`**: Expected answer from dataset 
- **`ground_truth_doc_ids`**: Document IDs from original dataset
- **`response_time`**: Time taken to generate answer (seconds)
- **`search_method`**: GraphRAG search method used ("local" or "global")

## Usage

These files are compatible with the evaluation framework:
- Can be used for Semantic Answer Similarity (SAS) evaluation
- Compare generated vs ground truth answers
- Analyze response times and success rates
- Study differences between local vs global search methods

## Generation Command

Files were generated using:
```bash
cd eval
python generate_answers.py --workspace ../workspace --questions 10 --search-method local
```
